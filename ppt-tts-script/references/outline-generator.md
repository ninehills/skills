# 大纲生成（Step 2）详细指南

## 任务

分析标准化素材库，生成层次化的演讲大纲，包括节的划分、每节包含的页面、节主题和风格提示。

## 输入

- `01_materials/index.json` — 素材索引
- `01_materials/slide-XX.md` — 各页面的 Markdown 内容

## 分析方法

### 第一步：内容分析

逐页读取 `slide-XX.md`，识别页面类型：

| 页面类型 | 特征 |
|---------|------|
| 封面页 | 只有标题/副标题，无正文 |
| 目录页 | 包含编号列表或章节概览 |
| 过渡页 | 只有一句话或章节标题 |
| 内容页 | 有实质性文字、数据、图表说明 |
| 总结页 | "总结"、"小结"等关键词 |
| 结尾页 | "谢谢"、"Q&A"、联系方式 |

### 第二步：节划分

基于内容逻辑进行划分：
- 每节 3-15 页
- 节边界通常在过渡页之后
- 相关内容归入同一节
- 保持叙事逻辑的完整性

### 第三步：风格匹配

根据内容类型选择风格提示：

| 场景 | 风格提示示例 |
|------|------------|
| 产品发布会 | 热情、自信、专业，语速适中偏快 |
| 学术报告 | 严谨、学术、清晰，语速适中 |
| 企业培训 | 亲切、耐心、互动，语速适中偏慢 |
| 商业演示 | 自信、专业、有说服力，语速适中 |
| 技术讲解 | 清晰、准确、逻辑强，语速适中 |

### 第四步：时间估算

- 快速语速：~200 字/分钟
- 中等语速：~180 字/分钟
- 慢速语速：~150 字/分钟
- 每页基础讲解：30-60 秒
- 考虑停顿和强调的额外时间

## 质量要求

- 所有页面都必须被分配到某个节（不遗漏）
- 页码范围连续无重叠
- 节标题简洁（10-50 字），能概括本节核心内容
- 客观分析，不添加素材中未提及的信息
